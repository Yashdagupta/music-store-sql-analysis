# Music Store SQL Analysis 🎵

## 📌 Project Overview

This project analyzes a music store database using SQL to explore customers, employees, artists, albums, tracks, genres, invoices, and sales-related data.

The project focuses on writing SQL queries to extract meaningful information from the database and answer different business-related questions.

## 🎯 Objectives

- Analyze music store customer and sales data
- Explore artists, albums, tracks, and genres
- Analyze customer and employee information
- Extract meaningful insights using SQL queries
- Practice SQL concepts on a real-world style database

## 🛠️ Tools & Technologies

- SQL
- SQL Server
- Music Store Database

## 📊 SQL Concepts Used

- SELECT and WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- CASE Statements
- JOINs
- Subqueries
- UNION
- CTE
- Recursive CTE
- Window Functions
- Ranking Functions
- LEAD and LAG
- Data Filtering and Analysis

## 📈 Analysis Performed

- Customer analysis
- Employee analysis
- Artist and album analysis
- Genre analysis
- Track analysis
- Sales and invoice analysis
- Customer purchase analysis
- Ranking and comparison using window functions
- Hierarchical analysis using recursive CTEs

## 🔍 Key Insights

The project demonstrates how SQL can be used to analyze relational data, identify patterns, compare records, rank results, and answer business-related questions from a music store database.
